# Проектная работа «Посмотри в окно»

Сервис для просмотра видеороликов из разных городов в разное время суток.

## Использованные технологии:
- HTML5 (семантическая разметка, использование тегов `<template>`)
- CSS3 (Flexbox, кастомные чекбоксы на псевдоэлементах, псевдоклассы `:focus-visible`, `:has()`, стилизация скроллбара)
- JavaScript (работа с API, подгрузка карточек, фильтрация)
